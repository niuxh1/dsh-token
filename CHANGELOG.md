# Changelog

## 0.1.0 — 2026-10-27

- First public release.
- Settings page with five usage metrics, GitHub-style activity heatmap,
  daily trend chart and model distribution.
- Workspace filter, Chinese/English copy, DSH light/dark theme tokens.
- Incremental persistent cache, background warm-up and live increments.
- Controlled raw-log fallback for session logs the installed harness refuses to
  read because of unknown event types.
